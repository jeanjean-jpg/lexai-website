Introducere

Ce este LEX AI?

LEX AI este o aplicație desktop pentru cabinete de avocatură din România, care oferă asistență juridică prin AI. Folosește modele Claude de la Anthropic, dar rulează complet pe calculatorul tău — datele clienților, dosarele și conversațiile nu ajung pe servere externe.

Aplicația include 9 agenți AI specializați pe ramuri ale dreptului român, un corpus juridic intern cu peste 5.000 de articole din coduri, sistem de gestionare dosare, urmărire termene și generare automată de documente juridice.

Cerințe de sistem

  • Windows 10 sau 11 (build oficial); macOS 12+ (build secundar)
  • 4 GB RAM minim, 8 GB recomandat pentru indexare documente
  • 2 GB spațiu liber pentru aplicație + corpus juridic
  • Conexiune internet pentru API Anthropic (nu este necesară pentru corpusul juridic intern)
  • Cheie API Anthropic obținută de la console.anthropic.com

Primii pași după instalare

  1. Descarcă și instalează — aplicația folosește instalator Squirrel pe Windows (1-click), DMG pe macOS
  2. Introduce cheia API Anthropic — Setări → API Key (vezi secțiunea Configurare inițială)
  3. Configurează numele cabinetului — va apărea în documentele generate și antetele AI
  4. Indexează primul folder — Setări → Foldere → Adaugă (recomand un folder de modele și unul de cazuri)
  5. Creează primul agent — Tab Agenți → Adaugă din template (ex. Avocat Civil)
  6. Pornește o conversație — selectează agentul, scrie întrebarea

Configurare inițială

Pasul 1: Cheia API Anthropic

LEX AI folosește modelele Claude de la Anthropic. Plătești Anthropic direct pe baza utilizării — costul este separat de licența LEX AI.

Cum obții cheia

  1. Mergi la console.anthropic.com și creează un cont
  2. Adaugă o metodă de plată (card bancar)
  3. Mergi la API Keys și apasă Create Key
  4. Copiază cheia generată (începe cu sk-ant-api03-...)

Configurare în LEX AI

Deschide aplicația → Setări → API Key → Lipește cheia → Validează și salvează. Cheia este criptată local cu DPAPI (Windows) sau Keychain (macOS).

Cost estimativ
Pentru un cabinet de avocatură cu utilizare normală — estimare €10-40 / lună. Haiku (rezumate documente) este foarte ieftin; Sonnet (chat) este moderat; Opus (cercetare juridică) este premium. Vezi anthropic.com/pricing pentru tarifele exacte actualizate.

Pasul 2: Profilul cabinetului

Numele cabinetului apare în:

  • Antetul documentelor generate (cereri, întâmpinări, notificări)
  • Semnătura comunicărilor agenților
  • Backup-uri (denumire fișiere)
  • Titlebar-ul aplicației

Setări → Cabinet → completează: denumire, sediu, CUI, persoană de contact, email cabinet. Aceste informații rămân local și nu sunt trimise nicăieri în afara documentelor pe care le generezi tu.

Pasul 3: Creează primul agent

Tab Agenți → + Adaugă → alege:

  • Template — unul dintre cele 9 disponibile sau Custom
  • Model — Haiku (rapid, ieftin), Sonnet (echilibrat), Opus (profund)
  • Acces foldere — bifează folderele pe care agentul le poate citi
  • Acces web — pornit / oprit (per agent)
  • Note persistente — text adițional injectat la fiecare conversație

Agenți juridici

Un agent este un assistant AI cu un prompt configurat pentru o ramură specifică de drept. Agentul vede contextul fiecărei conversații: dosarul (dacă e selectat), documentele atașate, agenda activă, și cele 12 articole din corpus retrieved automat pentru fiecare întrebare.

Cum funcționează un agent

Când scrii un mesaj, sistemul:

  1. Caută în corpusul juridic — BM25 retrieval, top 12 articole relevante
  2. Citește contextul dosarului — dacă conversația e legată la un dosar
  3. Adaugă agenda activă — termene din 30 zile
  4. Trimite la Claude — promptul agentului + contextul + mesajul tău
  5. Procesează răspunsul — detectează blocuri de documente, termene, comenzi către alți agenți

Cei 9 agenți disponibili

Apasă pe fiecare card pentru detalii complete — domeniu, exemple, când să escaladezi la alt agent.

Crearea unui agent personalizat

Pe lângă cele 9 template-uri, poți crea agenți custom cu prompt propriu. Util pentru:

  • Specializare îngustă (ex. Drept Sportiv, Drept Maritim)
  • Stil de comunicare specific (ex. agent care răspunde doar pe scurt, bullet-points)
  • Limbi străine (ex. agent care răspunde în engleză pentru clienții străini)
  • Roluri auxiliare (ex. Verificator citări, Calculator termene)

Limita: maxim 15 agenți custom per instalare. Cei 9 built-in sunt în plus.

Modul ACTIV — colaborare între agenți

Când e activat, un agent primar poate trimite întrebări laterale către alți agenți în timpul unei conversații, fără intervenția ta. Util când o întrebare are componente multidisciplinare.

Exemplu: ceri Avocatului Penal o cerere de recurs care include un capăt civil cu calcul de prejudiciu fiscal. Avocatul Penal cere automat:

  • Avocat Civil → analiză temei răspundere
  • Drept Fiscal → calcul prejudiciu și accesorii

Sinteza apare ca un singur răspuns coordonat, cu marcaj transparent în UI care arată ce agenți au contribuit la ce parte.

Modul ORCHESTRAT

Variantă mai puternică decât ACTIV. Agentul primar devine coordonator, descompune sarcina în sub-task-uri și le delegă paralel. Folosit pentru:

  • Analize complexe care necesită expertiză din 3+ ramuri
  • Generarea de documente lungi cu secțiuni specializate
  • Due diligence pre-tranzacțional

Costul de tokeni este mai mare (multiple apeluri API). Recomandat doar când e nevoie.

Limite și sfaturi

Atenție
AI-ul poate genera răspunsuri convingătoare dar incorecte. Verifică întotdeauna referințele legale pe legislatie.just.ro pentru versiunea în vigoare. Corpusul intern conține textul la momentul descărcării — modificările legislative ulterioare pot să nu fie reflectate.
  • Întreabă specific. "Care e termenul de prescripție pentru X?" e mai bun decât "Spune-mi despre prescripție."
  • Atașează documentele relevante. Agentul vede mai bine cu context.
  • Verifică articolele citate. Sistemul minimizează halucinațiile prin injecție de context, dar nu garantează corectitudinea pe 100%.
  • Folosește dosare. Conversațiile legate la dosar produc răspunsuri mai relevante.

Corpus juridic

Ce este corpusul juridic intern

O bază de date SQLite locală cu peste 5.000 de articole din principalele coduri și legi românești, indexată cu FTS5 (full-text search) și ranking BM25.

Cum funcționează căutarea automată

Sistemul folosește FTS5 (SQLite full-text search 5) cu ranking BM25 — același algoritm folosit de Lucene și Elasticsearch. Pentru fiecare mesaj scris în chat:

# Pipeline retrieval — simplificat
query = preprocess(user_message)
# tokenizare + diacritice + stem românesc

candidates = sqlite.execute(
  "SELECT art_id, snippet(corpus, ...) "
  "FROM corpus_fts WHERE corpus_fts MATCH ? "
  "ORDER BY bm25(corpus_fts) LIMIT 12",
  [query]
)

context = inject_into_prompt(candidates)
# articolele apar ca CONTEXT VERIFICAT înainte de întrebare

Adăugare surse externe

Setări → Corpus Juridic → + Adaugă:

  • URL — link către lege pe legislatie.just.ro sau alt portal oficial; aplicația parsează HTML-ul și extrage articolele
  • Fișier — PDF / DOCX / TXT cu text de lege; recunoaște automat structura "Art. N." și "alin. (X)"
  • Decizii — decizii ICCJ, CCR, CJUE adăugate ca articole speciale (citabile distinct)

Limitări

Corpusul conține textul la momentul descărcării. Modificările legislative ulterioare (ex. OUG-uri publicate săptămâna trecută) nu apar până la următoarea actualizare a aplicației sau adăugarea manuală. Pentru legi noi recente, folosește monitorul RSS al Monitorului Oficial (vezi secțiunea Setări).

Documente și fișiere

Adăugarea folderelor supravegheate

Tab Fișiere → + Folder → selectează un director. Aplicația indexează recursiv toate fișierele compatibile și le supraveghează pentru schimbări (file watcher).

Formate suportate

  • .pdf — text extras + OCR Tesseract dacă PDF e scanat
  • .docx — text + structură (titluri, liste)
  • .txt, .md — direct
  • .png, .jpg, .tiff — OCR Tesseract (RO + EN)
  • .rtf, .odt — convertite cu Pandoc embedded

Indexare automată + rezumare

Fiecare fișier indexat primește un rezumat scurt generat de Claude Haiku (5-8 propoziții). Rezumatele sunt vizibile în panoul Fișiere și sunt folosite pentru retrieval rapid când agentul caută documente.

Atașare document la conversație

În chat → pictograma 📎 sau trage fișierele direct peste fereastră (drag-and-drop). Ambele metode acceptă orice tip de fișier; textul din DOCX, PDF și fișiere text este extras integral, imaginile sunt trimise lui Claude Vision, iar scurtăturile web .url către imagini sunt descărcate automat. Atașările cu agrafa sunt valabile pentru mesajul respectiv.

Fișiere per sarcină

Pentru fișiere legate permanent de o conversație, folosește butonul 📁 Fișiere din antetul chatului. Atașezi foldere sau fișiere individuale care rămân disponibile pe toată durata sarcinii. Când o sarcină are fișiere atașate, agentul citește exclusiv acel set — înlocuiesc folderele globale ale agentului, asigurând izolare totală între dosare (fără bleed de context).

  • Agentul primește un manifest complet al fișierelor — știe exact câte sunt și care.
  • Conținutul documentelor este pus în cache, deci mesajele ulterioare sunt rapide și mai ieftine.
  • Poți atașa fișiere chiar înainte de a începe conversația — sarcina se creează automat.

Generarea documentelor

Cere agentului "Redactează o cerere/contract/notificare pentru [situație]". Răspunsul include un bloc structurat pe care aplicația îl detectează și îl salvează ca fișier.

Format ieșire
Implicit DOCX (cu stiluri ierarhice). Schimbi cu butonul de format din composer: DOCX / PDF / TXT. Câmpurile variabile (numele clientului, sume, date) sunt marcate cu [PARANTEZE DREPTE MAJUSCULE] pentru completare manuală.

Dosare

Crearea unui dosar nou

Tab Dosare → + Dosar nou. Câmpuri:

  • Titlu — denumirea dosarului (ex. "Popescu vs. Parchet ICCJ")
  • Număr dosar — format standard (ex. 4521/2025)
  • Instanță — Tribunal, Curte de Apel, ICCJ, Judecătorie
  • Client — nume + contact (email, telefon, adresă)
  • Stadiu — fond / apel / recurs / executare
  • Note interne — text liber, vizibil agentului

Legarea documentelor la dosar

În detalii dosar → Documente → + Adaugă din fișiere sau drag-and-drop direct. Documentele rămân stocate în locația originală (nu se copiază) — se păstrează doar o referință.

Conversații în context dosar

Când deschizi o conversație din ecranul unui dosar, agentul primește automat:

  • Datele dosarului (titlu, număr, instanță, client, stadiu)
  • Documentele atașate (rezumate scurte + acces la text complet la cerere)
  • Termenele și sarcinile dosarului
  • Conversațiile anterioare pe același dosar (memorie continuă)

Agenda — Termene și sarcini

Detecție automată

Agenții identifică automat termene din:

  • Conversații ("termenul de recurs este 10 zile de la comunicare...")
  • Documente indexate (citații, încheieri de ședință)
  • Monitorul Oficial (modificări care creează termene de aplicare)

Termenele detectate apar într-un panou de confirmare — accepți, modifici sau respingi înainte de a fi salvate.

Tipuri

  • Termen procesual — depunere act, comunicare, opțiune (galben)
  • Scadență — plată, executare obligație (portocaliu)
  • Depunere — act la grefă, ANAF, ONRC (galben)
  • Prescripție — termen de prescripție extinctivă (roșu — critic)
  • Manual — orice altceva pe care îl creezi tu

Marcarea ca rezolvat

În agenda → click pe termen → Marchează rezolvat. Istoricul rămâne accesibil. Termenele rezolvate nu mai apar în notificările zilnice.

Filtrul Expirate

Termenele depășite nu mai aglomerează categoria Urgente — au propriul filtru Expirate (după Rezolvate), cu un contor separat. Click pe orice termen expirat pentru a-l reprograma (dată nouă) sau a-l marca rezolvat.

Setări

API Key Anthropic

Vezi secțiunea Configurare inițială.

Tema

Întunecat (implicit, recomandat pentru utilizare îndelungată) sau deschis. Schimbarea se aplică instant fără restart.

Backup automat

Setări → Backup → configurează:

  • Folder destinație (recomand un drive extern sau folder cloud sincronizat)
  • Frecvență: zilnic / săptămânal / la închidere
  • Ora exactă pentru zilnic
  • Număr de copii păstrate (rolling backup)

Backup-ul include: SQLite database, configurări, dar NU cheia API (rămâne în keystore-ul sistemului).

Monitorul Oficial RSS

Activează în Setări → Monitorul Oficial. Sistem polling la RSS-ul oficial, parsare și notificare când apare o lege în categoriile bifate (Penal, Civil, Fiscal, etc.). Notificările apar în panoul Notificări și pot declanșa o re-indexare automată dacă activezi opțiunea.

Facturare & costuri API

Setări → Facturare & Costuri API oferă trei instrumente pentru urmărirea consumului:

  • Consolă Anthropic — butoane directe către sold și adăugare credite (soldul exact e disponibil doar în consolă).
  • Consum sesiune — contor live: tokeni intrare/ieșire, apeluri și cost estimat în USD.
  • Raport 30 zile — cheltuieli zilnice prin cheia Admin API (sk-ant-admin…), criptată local cu DPAPI. Disponibil pentru contul Avocat.

Gestionare utilizatori

Suport pentru avocat + asistenți, fiecare cu cont local. Permisiuni configurabile:

  • Avocat (admin) — toate operațiile
  • Asistent — citire dosare, redactare cereri, fără ștergere
  • Custom — bifare granulară per acțiune

Import / Export

Export complet: ZIP cu toate dosarele, documentele linkate (referințe + opțional copie), conversațiile, configurările. Util pentru migrare între calculatoare sau backup manual.

Confidențialitate și securitate

LEX AI este construit cu principiul privacy by default. Următoarele garanții se aplică:

Date locale

  • Niciun cont, niciun login pe servere LEX AI — nu există o platformă cloud
  • Baza de date SQLite locală: C:\Users\[user]\AppData\Roaming\LexAI\lexai.db (Windows) / ~/Library/Application Support/LexAI/lexai.db (macOS)
  • Documentele indexate rămân în locațiile lor originale (referință, nu copie)
  • Backup-urile sunt scrise în folderul pe care îl alegi tu

Criptare

  • Cheia API Anthropic: criptată cu DPAPI (Windows) sau Keychain (macOS) — nu poate fi citită de alt utilizator pe același calculator
  • SQLite cu extensia SQLCipher (AES-256) — opțional, activabil în Setări
  • Comunicarea cu Anthropic: HTTPS / TLS 1.3

Datele trimise la Anthropic

Când agentul răspunde, sunt trimise la API:

  • Promptul agentului (configurabil)
  • Textul conversației curente
  • Articolele de context retrieved din corpus (text scurt)
  • Documentele atașate explicit la mesaj (text integral)

NU sunt trimise: toate documentele indexate, dosarele neselectate, conversațiile cu alți agenți. Conform politicii Anthropic API (nu Claude.ai consumer), conversațiile nu sunt folosite pentru antrenament.

Recomandări

  • Activează SQLCipher pentru bază de date criptată
  • Configurează backup zilnic pe drive extern
  • Nu partaja calculatorul cu utilizatori care nu fac parte din cabinet
  • Pentru date super-sensibile (clienți VIP, dosare penale grave), folosește un agent cu acces restrictiv la foldere

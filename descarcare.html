Ghid de instalare — Windows

01
Descarcă instalatorul
Apasă butonul Descarcă pentru Windows de sus. Fișierul LexAI-Setup-1.0.3.exe se salvează în Downloads.
02
Verifică checksum-ul (opțional dar recomandat)
Deschide PowerShell în folderul Downloads și rulează:
Get-FileHash LexAI-Setup-1.0.3.exe -Algorithm SHA256
Compară rezultatul cu valoarea SHA-256 afișată sub butonul de download.
03
Lansează instalatorul
Dublu-click pe LexAI-Setup-1.0.3.exe. Squirrel instalează aplicația în %LOCALAPPDATA%\LexAI fără prompt UAC (per-user install). Durează ~30 secunde.
04
Pornește LEX AI
Aplicația se deschide automat după instalare și creează un shortcut pe Desktop și în Start Menu. La prima rulare, va indexa corpusul juridic intern (~5 minute, doar o singură dată).
05
Configurează cheia API Anthropic
Setări → API Key → lipește cheia ta de la console.anthropic.com (începe cu sk-ant-api03-) → Validează și salvează. Cheia se criptează cu DPAPI și nu părăsește calculatorul.
06
Indexează primul folder
Setări → Foldere → + Folder → selectează un director cu modele sau cazuri. Indexarea pornește în background. Acum poți deschide un chat cu primul agent.

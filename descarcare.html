Îmbunătățiri

  • Bară de progres la actualizare — la descărcarea și instalarea unei versiuni noi vezi o bară de progres și un avertisment clar să nu închizi aplicația în timpul procesului
  • Actualizare protejată — fereastra de actualizare nu mai poate fi ascunsă în timpul descărcării sau instalării, ca să nu fie întreruptă din greșeală

Funcționalități noi

  • Alegere plan la activare — pe ecranul de licență poți selecta planul (lunar sau permanent), iar butonul de cumpărare te duce direct la opțiunea aleasă
  • Logo și pictogramă noi — noua identitate vizuală LEX AI pe aplicație și în bara de activități
  • Perioadă de trial de 14 zile — acces complet gratuit, fără card
  • Mod pledoarie — comutator per sarcină: documentele generate devin mai ample și persuasive, în registru de pledoarie, fără a inventa fapte sau articole
  • Fișiere sarcină — atașează foldere sau fișiere specifice unei sarcini; agentul citește exclusiv acel context
  • Tab Expirate în Sarcini — termenele depășite, separate de cele active
  • Indicator online/offline în bara de sus
  • Actualizări automate cu confirmare — ești întrebat înainte de a descărca o versiune nouă

Îmbunătățiri

  • Răspunsuri și documente curate — fără marcaje markdown reziduale (asteriscuri) în chat sau în actele generate
  • Regăsire mai precisă din corpus: rescriere interogare, rerank, verificarea citărilor și segmentare pe articole
  • Dosare: agenții citesc conținutul real al actelor (DOCX/PDF), nu doar denumirile
  • Buget de context mărit per sarcină (~100k tokens) pentru mai multe documente
  • Indexarea surselor web este reluabilă după întrerupere (utilă pentru codurile mari)

Remedieri

  • Eliminate asteriscurile (**) reziduale din conversații și din documentele DOCX/PDF/TXT
  • Versiunea aplicației este afișată corect în bara de titlu
  • Fereastra de actualizare rămâne afișată până la un răspuns explicit
  • Corectată buclă de repornire la instalarea actualizărilor (Squirrel)

Ghid de instalare — Windows

01
Descarcă instalatorul
Apasă butonul Descarcă pentru Windows de sus. Fișierul LexAI-Setup.exe se salvează în Downloads.
02
Sursă de încredere
Instalerul este descărcat direct de pe pagina oficială GitHub Releases a LEX AI. Asigură-te că adresa începe cu github.com/jeanjean-jpg/lexai-releases înainte de a rula fișierul.
03
Lansează instalatorul
Dublu-click pe LexAI-Setup.exe. Squirrel instalează aplicația în %LOCALAPPDATA%\LexAI fără prompt UAC (per-user install). Durează ~30 secunde.
04
Pornește LEX AI
Aplicația se deschide automat după instalare și creează un shortcut pe Desktop și în Start Menu. La prima rulare, va indexa corpusul juridic intern (~5 minute, doar o singură dată).
05
Configurează cheia API Anthropic
Setări → API Key → lipește cheia ta de la console.anthropic.com (începe cu sk-ant-api03-) → Validează și salvează. Cheia se criptează cu DPAPI și nu părăsește calculatorul.
06
Indexează primul folder
Setări → Foldere → + Folder → selectează un director cu modele sau cazuri. Indexarea pornește în background. Acum poți deschide un chat cu primul agent.
